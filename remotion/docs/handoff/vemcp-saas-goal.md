VEMCP (Video Editor MCP) is the foundation for a SaaS product modeled on Submagic and Captions.ai — AI-generated captions, B-roll insertion, and autocut, all driven by natural-language commands through MCP. Dev happens in Cursor with Claude Code.

**Roadmap order:** captions first (via Remotion — see [[captions-remotion-architecture]]), then B-roll overlays, then autocut. Established in a planning chat on 2026-06-04 (shared session, Mostafa).

**Why:** context for feature priorities — work on the `feature/captions-remotion` branch is step one of a larger SaaS build, not a standalone script.
